# Best Burgers — V1.1

Primera versión de la web app del menú digital de Best Burgers.

## Objetivo de esta versión

- Mobile-first
- Navegación por categorías
- Scroll suave
- Header fijo
- Barra de categorías horizontal y desplazable
- Categoría activa durante el scroll
- Botón "volver arriba"
- Pantalla de carga breve
- Modo claro / oscuro
- Información ficticia del restaurante
- Botones de teléfono, WhatsApp, Instagram y Maps
- Funciona sin framework y sin dependencias externas

## Imágenes temporales

`starters.png` y `vegan.png` son las dos imágenes proporcionadas para este prototipo.

`desserts-placeholder.png` y `drinks-placeholder.png` son copias temporales utilizadas para que la estructura completa pueda probarse desde ahora.

Cuando tengan las imágenes definitivas:

1. Reemplacen `desserts-placeholder.png` por la imagen real de postres.
2. Reemplacen `drinks-placeholder.png` por la imagen real de bebidas.
3. Si quieren conservar los nombres más limpios, pueden renombrarlas a `desserts.png` y `drinks.png` y actualizar las rutas en `index.html`.

## Ejecutar localmente

No requiere instalación.

Simplemente abran `index.html` en un navegador.

Para una experiencia más parecida a producción, también pueden abrir la carpeta con VS Code y usar una extensión como Live Server.
